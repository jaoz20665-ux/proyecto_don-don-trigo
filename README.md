# Don Trigo: sitio web de panadería

Sitio web base para una panadería y cafetería, hecho como proyecto institucional. Los datos de contacto son de ejemplo.

Ver el sitio: https://jaoz20665-ux.github.io/proyecto_don-don-trigo/

## Qué incluye
- Diseño adaptable a celulares y computadoras.
- Menú con 16 productos: panes, cafés y acompañantes.
- Carrito de compras: agregar, quitar, total en tiempo real y confirmación del pedido.
- Animaciones suaves y navegación accesible con teclado.

## Tecnologías
HTML, CSS, JavaScript y Tailwind CSS.
